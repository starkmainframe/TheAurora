Bring your display to life.

Connect a USB data cable, select the exact board printed on your device, then install. Use Chrome or Edge on a desktop.

This browser does not support Web Serial. Use desktop Chrome/Edge, or the USB instructions in the README.Open this flasher over HTTPS.

Both boards use an ESP32-S3, but have different pin maps. Select your board before connecting.

Checking published firmware…

Web installation resets saved WiFi and location. Choosing erase also clears cached forecasts. If the port will not connect: hold BOOT, tap RESET, release BOOT, and try again. Press RESET after flashing.

01 / Join the setup network

Connect to TheAurora-Setup. Open 192.168.4.1 if the captive page does not appear, then enter your 2.4 GHz WiFi.

02 / Put yourself on the map

On home WiFi, open theaurora.local. Enter coordinates or tap “Use this phone’s location.”

03 / Swipe through the sky

Globe → Kp → Here. Updates every 15 minutes by default. A stale marker appears if data cannot refresh.
